# 基于vscode的arm-none-eabi-gcc开发和调试

对于vscode下的arm-none-eabi-gcc开发调试, 有两个方案。

## 使用vscode插件

使用stm32提供的"STM32CubeIDE for Visual Studio Code"插件，直接安装即可，会配置需要的cmake、make、arm-none-eabi-gcc、openocd等环境。

优点是集成度高，开箱即用，缺点是仅支持st自家的芯片方案，使用其它家芯片还需要自行搭建。

## 构建方案自行开发

### 构建项目

使用STM32CubeMX生成使用Makefile的基本项目，在项目目录下创建.vscode目录，创建tasks.json和launch.json文件。

分别如下所示。

- tasks.json

增加编译选项

```json
{
    "tasks": [
        // 编译任务
        {
            "label": "build",               // 任务名称，其它任务请求使用
            "type": "shell",                // 任务类型，shell表示执行命令行语句
            "command": "make",              // 执行make命令
            "args": [
                "-j2",                      // 执行make命令附带参数，指定并行编译任务数为2
                "DEBUG=1"
            ],
            "group": {
                "kind": "build",
                "isDefault": true
            },
            "problemMatcher": "$gcc",   //问题匹配器，异常指定输出gcc相关的问题
            "detail": "Task generated by Debugger."
        },

        // 清理任务
        {
            "label": "clean",
            "type": "shell",
            "command": "make",
            "args": [
                "clean"
            ],
            "group": {
                "kind": "build",
                "isDefault": false
            },
            "problemMatcher": "$gcc",
            "detail": "Task generated by Debugger."
        },
    ],
    "version": "2.0.0"
}
```

- launch.json

配置调试时的选项。

```json
{
    "version": "0.2.0",
    "configurations": [
        {
            "name": "Debug Microcontroller",
            "type": "cortex-debug",         // 使用cortex-debug插件
            "request": "launch",
            "servertype": "openocd",        // 使用openocd作为调试服务器
            "cwd": "${workspaceFolder}",
            "executable": "${workspaceFolder}/build/stm32h743.elf",
            "configFiles": [                  // 配置文件(位于openocd目录下，根据型号选择)
                "interface/stlink-v2.cfg",
                "target/stm32h7x.cfg"
            ],
            "svdFile": "${workspaceFolder}/STM32H7x.svd",   // 从DFP中获取的SVD文件，放在目录下方便查看寄存器
            "preLaunchTask": "build",
            "runToEntryPoint": "main",
        }
    ]
}
```

完成后使用F5即可编译并进行调试。
