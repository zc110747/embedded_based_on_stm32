## 基础数据类型

基础类型表格如下

| 类型 | 说明 | 长度 |
| --- | --- | --- |
| char | 字符类型 | 1字节 |
| short | 短整型 | 2字节 |
| int | 整型 | 2/4字节，与系统和编译器有关 |
| long int | 整型 | 至少4字节，与系统和编译器有关 |
| long long int | 长整型 | 至少8字节，与系统和编译器有关 |
| float | 单精度浮点类型 | 4字节 |
| double | 双精度浮点类型 | 8字节 |
| long double | 长双精度浮点类型 | 至少8字节，与系统和编译器有关 |

单片机堆栈指针的字节数 与系统以及编译器有关，其中32位为4字节，64位为8字节。

在软件开发中，使用`stdint.h`中的类型如int8_t、int32_t而不是这些基础类型，可以提高可移植性。

## 常见预编译指令和功能说明

```c
// #include
#include <stdio.h>      // 包含函数库 

// #define
#define VER   1         // 宏定义

// #if
#if VER == 1            // 如果，条件判断选择
#elif VER == 2      
#else           
#endif

// #ifdef
#ifdef (VER)            // 如果，定义判断选择
#else
#endif

// #ifndef
#ifndef (VER)           // 如果，定义未判断选择
#else          
#endif

// #warning
#warning "this is a warning"   // 警告输出

// #error
#error "this is a error"        // 错误输出
```

其中#define和typedef是比较重要的指令，具有如下差异

1. #define可以用于类型、数值和变量的定义，typedef仅可以用于变量定义
2. typedef重定义类型时会进行检查，可以避免出错，#define只进行替换，不保证是否出问题

- 利用#define定义一年多少秒钟

```c
#define SECOND_PER_YEAR     (unsigned long long)(365*24*60*60)
```

- 利用#define定义宏来表示程序代码段，要带括号避免有歧义

```c
// 如定义一个标准宏，返回较小的值
#define  MIN(A,B)    ((A)<=(B)?(A):(B))
```

宏#define的这种运用主要方便移植，如把能够多次利用的底层硬件处理模块用宏定义，在移植时仅需要修改宏定义部分即可，极大地减少出错可能和时间消耗，宏定义的运用可能不影响当前软件的编写，但用的好的话会让以后的更新升级十分便利。

## 变量定义和声明，考察指针、函数指针、数组指针

读取指针变量优先级规则`() > [] > *`。

```c
// 整型a
int a;

// 指向整型的指针
int *a;

// 指向指针的指针，它指向的指针指向一个整型
int **a;

// 一个有10个整型的数组
int a[10];

// 一个有10个指针的数组，该指针指向一个整型变量
int *a[10];

// 一个指向有10个整型变量数组的指针
int (*a)[10];

// 一个指向函数的指针，该函数有一个整型参数并返回一个整型变量
int  (*a)(int);

// 一个有10个指针的数组,该指针指向一个函数，该函数有一个整型参数并返回一个整型数
int (*a[10])(int);
```

示例如下.

```c
#include <stdio.h>

int (*func)(int (*var)[10]);

int show_func(int (*var)[10])
{
    int i;

    for (i=0; i<10; i++)
    {
        printf("var[1][%d] = %d ", i, var[1][i]);
    }

    return 0;
}

int main(int argc, const char *argv[])
{
    int i, j;
    int a[2][10];
    int *b = &a[0][0];      // 指针
    int (*c)[10] = &a[0];   // 指向数组的指针

    for (j=0; j<10; j++)
    {
        for (i=0; i<2; i++)
        {
            a[i][j] = j + i;
        }
    }

    for (i=0; i<10; i++)
    {
        printf("b[%d] = %d ", i, b[i]);
    }
    printf("\r\n");

    func = show_func;
    func(c);

    return 0;
}
```

## 比较两组寄存器里有多少位不同

(1) 先将两个数使用`^`进行异或
(2) 右移与1进行与操作，判断不同位数
(3) 右移为0时提前结束，此时数目就是不同位的数目，位数减去这个值就是相同位的数目

```c
#include <stdio.h>

int main(int argc, char *argv[])
{
    int a = 0x35;
    int b = 0x24;
    int c, i, count;

    c = a^b;
    count = 0;
    for(i=0; i<32; i++)
    {
        if ((c&0x01) == 1)
            count++;
        c = c >> 1;
        if (c == 0)
            break;
    }

    printf("count:%d\r\n", count);
}
```

## static和extern的作用

static的用法如下。

1. 函数体内定义的静态局部变量，变量在函数调用过程中会保持上一次结束时的值
2. 在文件内部却在函数体外，声明为静态的变量或者函数只能被文件内的所有函数访问

总结：函数体内影响生存周期，函数体外影响可访问空间

extern用于声明外部变量和函数，使用extern声明后会在调用时链接查找外部函数或变量，避免警告。

```c
static int global_val = 0;      // 静态全局变量

extern void efunc(int val);     // 声明外部函数

static void func(void)          // 静态函数
{   
    static int local_val = 0;   // 静态局部变量

    efunc(local_val);
}
```

## const和volatile用法

const表示只读，避免误修改，增加程序的健壮性。

在单片机中，声明为const的变量会被存储到readonly存储区。

volatile，则是易变的，表示会被意想不到的改变

用途：

1. 并行设备的硬件寄存器(例如状态寄存器)
2. 一个中断服务历程访问的非自动变量
3. 多线程应用中共享的变量

一个变量可能即是const又是volatile吗？

可以的，如只读状态寄存器，const只读表示程序不应该试图修改它，但是它是volatile因为它可能被意想不到的改变

## 变量的置位和清除

整型变量a，写两段代码，置位bit3和清除bit3。

```c
// 置位数据
a |= (1<<3)

// 清除数据
a &= ~(1<<3)
```

取补码或者反码时要考虑到编辑器的位数，以及基本数据类型在不同位数的编辑器中不一样，要善于用~和<<,>>等位变量。

## 设置确定地址内的数据

设置一个绝对地址为0x67a9的整型变量的值为0xaa66

```c
// 声明变量并赋值
volatile int *ptr = (int *)0x67a9;
*ptr = 0xaa66

// 单步骤实现
*(volatile int * const)(0x67a9) = 0xaa66;
```

## 中断服务函数的注意点

1. 中断不能传递参数和返回值
2. 在许多编译器中，浮点数一般不可重入；即使允许,ISR中进行浮点运算效率很低，避免在中断种使用
3. 不可重入函数不要在中断中使用，无法进行资源保护
4. 中断和主循环中共用数据要声明为volatile，避免优化
5. 中断中不可以睡眠，可能无法

## 内存分配、静态存储区、堆和栈

1. 全局变量和静态变量：从静态存储区分配，内存在程序编译时分配并存在与整个程序周期中
2. 局部变量：从栈上分配，子函数调用时申请，结束后释放
3. 动态内存：从堆上分配，由程序员自己决定生存期，动态内存会产生内存碎片，比较好的减少方法就是申请->释放一一配对，在释放前不要申请新的动态内存。

## 大小端说明和判断方法

‌大端模式和小端模式的区别在于字节的存储顺序不同‌。

大端模式（Big-Endian）中，**数据的高字节保存在内存的低地址中**，而数据的低字节保存在内存的高地址中，存储模式类似把数据当作字符串顺序处理。

小端模式（Little-Endian）中，**数据的高字节保存在内存的高地址中**，而数据的低字节保存在内存的低地址中，存储模式将地址的高低和数据位权有效地结合起来

```c
#include <stdio.h>

union A
{
    unsigned int a;
    unsigned short b;  
};

int main(void) 
{
    // 使用union进行判断
    A test;
    test.a = 0xFFFF0000;
    if (test.b == 0x0000) { 
        printf("小端模式");
    } else {
        printf("大端模式");
    }

    // 使用指针强制转换
    unsigned int val = 0xFFFF0000;
    unsigned short *pstr = (unsigned short *)&val;
    if (*pstr == 0x0000) {
        printf("小端模式, 0x%x", *pstr);
    } else {
        printf("大端模式, 0x%x", *pstr);
    }
}
```

## 软件支持不同硬件的维护方法

这里仅限于运行平台相同，但是外设模块不同的设备。

一套代码支持不同硬件的方法如下：

(1) 设备分为软件+配置信息部分，配置信息额外烧录，启动时读取配置信息来执行不同的驱动分支，上层接口保持一致
(2) 设定硬件ID，可以是引脚状态、引脚电平、某些独有器件，检测到相应状态后作为配置信息，后续按照相同方法处理

一版软件支持不同硬件的方法如下：

(1) 通过宏定义，不同的版本执行不同的驱动分支流程，同时保证上层接口的一致性

## 软件产品开发流程

1. 市场调研
2. 项目立项，主要配合产品经理参与前期产品定义和项目规划
3. 产品基本架构设计,主要配合芯片/模组选型和功能需求分析，初步文档完善

5. 软件流程开发，在实际硬件板进行功能开发，并反馈结果，同时完善文档。
6. 产品优化和需求更新，主要结合开发遇到的软/硬件问题，配合硬件完善产品的功能，并解决伴随开发的需求更新问题。
7. 文档管理，开发文档，使用文档和后期维护文档完善
8. 产品测试和量产，配合测试工程师的电压稳定性，高低温，老化，产品需求方面的测试，解决反馈的问题。
